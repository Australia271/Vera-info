Vera

Vera è un gestore di password personale per Android e Windows, sviluppato per uso privato.

  • Le password sono cifrate sul dispositivo (AES-256-GCM, chiave derivata dalla master password con Argon2id).
  • La master password non viene mai salvata né inviata a nessuno.
  • Facoltativamente Vera può sincronizzare un file cifrato con il Google Drive dell'utente, usando solo il permesso che consente di vedere i file creati dall'app stessa.
