Informativa sulla privacy di Vera

Ultimo aggiornamento: 11 ottobre 2026.

Quali dati tratta Vera

Vera conserva le voci inserite dall'utente (per esempio nomi utente, password e note) in un caveau cifrato memorizzato sul suo dispositivo. Il contenuto è leggibile solo con la master password, che non viene mai salvata né trasmessa.

Nessuna raccolta di dati

Lo sviluppatore di Vera non riceve, non raccoglie e non può leggere i dati dell'utente. Vera non contiene sistemi di analisi, pubblicità o tracciamento.

Sincronizzazione con Google Drive (facoltativa)

Se l'utente la attiva, Vera usa l'autorizzazione di Google drive.file per creare e aggiornare un solo file, vera.vault, nel Google Drive dell'utente. Il file è già cifrato sul dispositivo prima del caricamento: Google non può leggerne il contenuto. Vera non può accedere agli altri file presenti nel Drive. I codici di accesso restano memorizzati, in forma cifrata, solo sul dispositivo dell'utente.

L'uso delle informazioni ricevute dalle API di Google rispetta la Google API Services User Data Policy, inclusi i requisiti di Uso limitato.

Cancellazione dei dati

L'utente può eliminare in qualsiasi momento il caveau dal proprio dispositivo, il file vera.vault dal proprio Drive e revocare l'accesso di Vera dalle impostazioni del proprio account Google.
